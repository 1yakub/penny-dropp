# Penny Dropp

Portfolio of a fictional artist, sold from a working vending machine. Tap a slot, or type a letter and a number, and the object falls into the bin.

Penny does not exist. Her objects, shows and prices are invented, and the pictures were made with an AI image generator.

## Stack

Next.js 16, React 19, Tailwind CSS 4, Motion 14. Static output, deployed on Vercel.

## Run it

```bash
npm install
npm run dev
```
